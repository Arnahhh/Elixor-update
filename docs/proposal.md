# HealthChain — Healthcare Appointment & Records Platform

## 1. Project Title

HealthChain — Healthcare Appointment & Records Platform

## 2. Problem Statement

A relational database system to manage patient appointments, doctor availability, medical records, prescriptions, and payments for a clinic, with role-based access for patients, doctors, and admins.

## 3. Objectives

- Enable patients to book and track appointments with doctors
- Allow doctors to manage availability and update appointment/record status
- Maintain a single normalized Users table with role-based access control
- Ensure secure authentication and data integrity across all records

## 4. Scope (Demo 1)

**Included:** Core schema (8 tables), JWT authentication, role-based access for patients/doctors/admins, appointment booking CRUD flow, basic dashboard UI.

**Excluded:** stored procedures, triggers, views, deployment, CI/CD — these are later phases.
